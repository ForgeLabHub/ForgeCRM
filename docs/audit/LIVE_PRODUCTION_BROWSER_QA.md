## 15. Дефекты

| ID | Severity | Компонент | Описание | Воспроизведение | Исправление |
| --- | --- | --- | --- | --- | --- |
| **D-1** | **P1** | Deployment config | `/ready` сообщает `commit=8d350b0`, хотя развёрнут код `main` (бандл совпал с `main`). Причина — устаревшая env `FORGECRM_COMMIT` на blitz.cloud. | Сравнить `/ready` с хэшами бандла; сборка `8d350b0` даёт другие хэши. | Обновить `FORGECRM_COMMIT` до SHA `main` или включить авто-подстановку. |
| **D-2** | P2 | Безопасность (CSP) | CSP только `report-only` — фактически не защищает, шумит в консоли. | Открыть `/login`, консоль. | Включить enforcing-CSP после наблюдения. |
| **D-3** | P3 | Наблюдаемость | `/metrics` без авторизации → `503` (не `401`). | `GET /metrics` → `503`. | Вернуть `401` либо документировать. |
| **D-4** | P3 | UX (MCP) | Credential с правами только на данные даёт `403` на `initialize`, т.к. протокол требует `ai.tools.execute`; UI это явно не подсказывает. | Создать credential без `ai.tools.execute` → `POST /mcp` → `403`. | Подсказать в UI, что для MCP-клиента нужен `ai.tools.execute`. |
| **D-5** | P3 | Валидация | `POST /api/v1/leads {}` создаёт лид с пустым `title` (у contacts/accounts/deals/tasks/tickets валидация есть). | `POST /leads` с пустым телом → `201`, `title:""`. | Требовать непустой `title` (или хотя бы одно поле). |

Дефектов, блокирующих работу продукта, **не найдено**. Все пять — P1–P3.

## 16. Непроверенное / ограничения

- **RBAC под ограниченной ролью:** негативный тест не выполнен — инвайт в production
  не отдаёт reset-токен (это правильно), поэтому войти как `analyst` нельзя без доступа
  к почте/БД. Права проверены структурно (14 ролей, 103 права, `403` по MCP-правам).
- **Массовый импорт/экспорт** реальными файлами — не выполнялись.
- **Внешние отправки** (Telegram/Email/Webhooks) — не выполнялись (выключены).
- **MFA enroll/verify** — не выполнялся (у аккаунта выключен).
- **Нагрузочное/параллельное тестирование** — не выполнялось.
- **Destructive-операции** (удаление организации и т.п.) — не выполнялись.

## 18. Итоговая оценка

**Статус: PASS (с оговорками).**

Опубликованный ForgeCRM — работоспособный, хорошо защищённый продукт. Проверены и
подтверждены: аутентификация и сессии, защита маршрутов, полный CRM CRUD через UI и API,
