ForgeCRM API

Version 0.1.0 · OpenAPI 3.1.0

/ — The server this document was generated from.

ForgeCRM REST API.

Authentication

Sign in with POST /api/v1/auth/login, which sets the session cookie `forgecrm_session`. State-changing requests must also send the CSRF token returned by GET /api/v1/auth/me in the `X-CSRF-Token` header.

Errors

Every failure returns RFC 9457 Problem Details with `type`, `title`, `status`, `detail`, `instance` and `retryable`, and repeats the machine-readable code under `error`. Branch on `error.code`; `title` is prose and may change. See docs/api/errors.md.

Collections

List operations accept `limit`, `offset`, `q`, `sort` and `order`, and return `{items, total, limit, offset}`. `limit` is clamped by the server, so a large value is not an error.

Long operations

Imports, migrations and exports return a job identifier instead of blocking the request. Poll GET /api/v1/jobs/{id}.

Permissions

Each operation states the permission it requires. A caller without it receives 403. Authorisation is enforced on the server; the interface only decides what to display.

Request body required

Records a consent decision.
