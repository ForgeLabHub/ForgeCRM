# Архитектурные решения (DECISIONS)

Здесь — решения, относящиеся к программе «Architecture Transformation». Они
дополняют основной набор ADR в [`docs/adr/`](../../adr/README.md), а не заменяют
его.

| ADR | Тема | Статус |
|---|---|---|
| [0013](0013-microservices-vs-modular-monolith.md) | Микросервисы vs модульный монолит | **Предложено** (требует решения владельца) |

## Действующие решения (в `docs/adr/`)

- [ADR 0001](../../adr/0001-hybrid-architecture.md) — гибридная архитектура
  (модульный монолит, два процесса). **Действует.**
- [ADR 0002](../../adr/0002-service-extraction-triggers.md) — измеримые триггеры
  выделения сервиса. **Действует.**
- ADR 0003…0012 — см. `docs/adr/`.

## Формат

Каждый ADR содержит: контекст, проблему, рассмотренные альтернативы, принятое
решение, последствия, компромиссы.
