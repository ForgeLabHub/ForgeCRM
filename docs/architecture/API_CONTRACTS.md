# Контракты API ForgeCRM

> Описывает **реальный** контракт на `main` @ `3424b3e`. Источник истины —
> генератор, а не этот документ.

## 1. Как устроен контракт

- Спецификация OpenAPI **генерируется** из живого роутера: `cmd/openapi-gen` →
  `docs/api/openapi.json` (185 путей, 240 операций).
- CI-гейт `openapi-check` падает, если спецификация разошлась с роутером.
  **Ручная правка запрещена.**
- Таблица контракта `internal/api/contract.go` (`APIContract`) называет реальный
  DTO для каждого маршрута. `contract_test.go` держит оба направления: нет
  выдуманных маршрутов (`TestNoRouteIsInvented`) и нет сирот-компонентов
  (`TestNoOrphanComponents`).
- Схемы выводятся из типов, которые используют обработчики, поэтому документ не
  может описывать форму, которую не принимает код.

## 2. Уровни доступа маршрута

Каждый маршрут обязан объявить один из трёх уровней, иначе генерация падает:

| Уровень | Объявление | Смысл |
|---|---|---|
| Разрешение | `s.perm(rbac.PermX)` | требуется право |
| Сессия | `openapi.SessionOnly` | сессия без конкретного права |
| Аноним | `openapi.Anonymous` | без сессии (закрытый список из 6) |

`Anonymous` — закрытый список; добавление означает новый неаутентифицированный
эндпоинт и требует причины.

## 3. Форматы

- Префикс: `/api/v1`.
- Формат: JSON; ошибки — единый конверт `httpx.WriteError` с кодом.
- Пагинация: `httpx.Pagination`; сортировка — `httpx.SortSpec` (вайт-лист).
- Идемпотентность изменяющих операций: заголовок `Idempotency-Key`; повтор с тем
  же ключом возвращает первый результат и помечается `Idempotent-Replay: true`;
  параллельный запрос — `409`. Ключ привязан к организации, пользователю, методу
  и пути (`internal/idempotency`).

## 4. Ключевые группы маршрутов

| Группа | Префикс | Права |
|---|---|---|
| CRM | `/api/v1/{accounts,contacts,leads,deals,pipelines,tasks,tickets}` | `deals.*`, `contacts.*`, `accounts.*`, `tickets.*`, `leads.*`, `tasks.*`, `pipelines.*` |
| Отчёты | `/api/v1/reports/*` | `reports.*` |
| Администрирование | `/api/v1/admin/*` | `admin.*` |
| Импорт | `/api/v1/import/*` | `import.*` |
| Интеграции | `/api/v1/integrations/*` | `integrations.*` |
| Уведомления | `/api/v1/notifications/*` | `notifications.*` |
| ИИ | `/api/v1/ai/*` | `ai.*` |
| MCP | `/api/v1/mcp` | `ai.*` + scope токена |
| События/вебхуки | `/api/v1/events/*` | `events.*` |
| Telegram | `/api/v1/telegram/webhook` | подпись/секрет |

Полный список — `docs/api/openapi.json`; интерактивная страница —
`docs/api/index.html`.

## 5. Контракты между модулями (Go)

Межмодульные вызовы внутри монолита — через **экспортируемые типы пакетов**, а не
HTTP. Пример: `crm.Service` вызывают и HTTP-обработчики, и MCP-инструменты, и
workflow, и worker. Это гарантирует, что права и валидация не разойдутся.

## 6. События

Контракт событий — в `EVENT_CATALOG.md`. Версия схемы — `schema_version`.

## 7. Проверка

| Утверждение | Команда |
|---|---|
| OpenAPI актуален | `go run ./cmd/openapi-gen -check` |
| Контракт целостен | `go test ./internal/api/ -run Contract` |
| Нет выдуманных маршрутов | `contract_test.go::TestNoRouteIsInvented` |
