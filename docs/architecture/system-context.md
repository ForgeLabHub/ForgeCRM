# Контекст системы

## Что такое ForgeCRM в одном абзаце

Self-hosted платформа для корпоративных данных: CRM-ядро (контакты, компании,
сделки, задачи, тикеты), импорт данных из внешних систем, автоматизация через
workflow и вебхуки, контролируемая AI-помощь. Работает без интернета и без
внешних провайдеров: каждая интеграция — опция, выключенная по умолчанию.

## Контекстная диаграмма

```
        ┌──────────────┐        ┌───────────────┐        ┌──────────────────┐
        │ Оператор CRM │        │  Администратор│        │ Внешняя система  │
        │ (браузер)    │        │  (браузер)    │        │ (ERP, скрипт,    │
        └──────┬───────┘        └───────┬───────┘        │  MCP-клиент)     │
               │ HTTPS                  │ HTTPS          └────────┬─────────┘
               ▼                        ▼                         │ HTTPS/webhook
        ┌──────────────────────────────────────────┐               │
        │ nginx (reverse proxy, TLS)               │◄──────────────┘
        └──────┬───────────────────────────────────┘
               │
               ▼
        ┌──────────────────────────────────────────┐      ┌──────────────────┐
        │ ForgeCRM API (Go, chi)                   │─────▶│ PostgreSQL 17    │
        │  аутентификация, RBAC, доменные модули   │      │ схема forgecrm   │
        └──────┬───────────────────────────────────┘      └──────────────────┘
               │ outbox/jobs                                    ▲
               ▼                                                │
        ┌──────────────────────────────────────────┐            │
        │ ForgeCRM worker (Go)                     │────────────┘
        │  вебхуки, workflow, retention, импорт    │
        └──────┬───────────────────────────────────┘
               │ опционально
               ▼
   ┌───────────────────────────────────────────────────────────┐
   │ SMTP · Telegram · S3-совместимое хранилище · AI-провайдер │
   │ (Ollama / OpenAI-совместимый) · OIDC-провайдер            │
   └───────────────────────────────────────────────────────────┘
```

Redis присутствует в compose как хранилище распределённого rate limit, но
платформа работает и без него (`FORGECRM_RATE_LIMIT_STORE=memory`).

## Границы поддержки

Заявлено и проверяется:

- **PostgreSQL 17** — единственная поддерживаемая СУБД. MySQL/MariaDB сознательно
  не поддерживаются, причины зафиксированы в
  [ADR 0008](../adr/0008-mysql-mariadb-datastore-blockers.md).
- **Linux + Docker Compose** — основной способ развёртывания. Бинарники собираются
  статически (`CGO_ENABLED=0`) и запускаются без контейнеров.
- **Chromium (Playwright)** — браузер, в котором проверяется UI.

Не заявлено (и не должно подразумеваться):

- работа без PostgreSQL или на встроенной БД;
- гарантии совместимости с каждым S3/SMTP/AI-провайдером — поддерживается протокол,
  а не список вендоров;
- Windows как серверная платформа (скрипты — bash);
- горизонтальное масштабирование без внешнего Redis (см.
  [ADR 0003](../adr/0003-multi-replica-safety-detour.md)).

## Внешние зависимости и режим отказа

| Зависимость | Обязательна | Поведение при отсутствии |
| --- | --- | --- |
| PostgreSQL | да | API не стартует, сообщает причину |
| Redis | нет | rate limit в памяти процесса |
| SMTP | нет | письма не отправляются, `ErrDisabled`, продукт работает |
| Telegram | нет | интеграция выключена |
| S3 | нет | вложения отключены, остальное работает |
| AI-провайдер | нет | AI-функции возвращают «не настроено» |
| OIDC | нет | локальная аутентификация |
