# Руководство по миграции ForgeCRM

Два разных смысла слова «миграция». Не путайте их.

## A. Миграция схемы БД (обычная разработка)

- Миграции — `backend/internal/migrations/NNNN_name.{up,down}.sql`, встроены в
  бинарник (`//go:embed`).
- Пары up/down **симметричны** (гейт `facts-gen`).
- Применяются API при `FORGECRM_MIGRATE_ON_START=true` или флагом `-migrate`.
- Изменение схемы требует **пересборки** образа.
- Проверка на чистой БД:

```bash
./scripts/integration-env.sh up
export FORGECRM_TEST_DATABASE_URL='postgres://forgecrm:forgecrm@127.0.0.1:55432/forgecrm_test?sslmode=disable'
cd backend && go test -tags=integration ./internal/migrate/... -count=1
```

## B. Миграция архитектуры (программа «Architecture Transformation»)

### B.1. Текущее состояние → что уже сделано

- `main` — модульный монолит (ADR 0001), 36 модулей извлекаются.
- Нет циклов, правила слоёв обеспечены тестами.
- События, outbox, идемпотентность, наблюдаемость — есть.

### B.2. Перенос модуля в другой проект (Этап E)

См. `PORTABLE_MODULES.md`. Кратко:

```bash
./scripts/extract-test/run.sh <module>   # доказывает извлечение
# скопировать пакет + зависимости из manifest.yaml, переписать импорты
# применить миграции из database.migrations, задать requires_env
```

### B.3. Переход к микросервисам (Этап C) — **не начат, требует решения**

Порядок, если решение принято:

1. **Решение владельца** по ADR 0001/0002 (см. `DECISIONS/` и ADR 0013).
2. **Разделение схем БД** (TD-2) + тест-хранитель владения данными.
3. **Пилот на одном сервисе** с наименьшей связностью (кандидат: `analytics` или
   `notifications`).
4. Контракты событий/API (частично есть).
5. Постепенное выделение по триггерам ADR 0002, а не «распил всего сразу».

**Запрещено:** создавать сервисы-обёртки, которые лишь проксируют в монолит;
начинать массовую миграцию без разделения данных.

### B.4. Откат

- Каждый этап — отдельный коммит; откат через `git revert <sha>`.
- Резервная точка: тег `backup/pre-arch-20261107` (исходный `main`).
- Миграции БД обратимы (пары down); схема не менялась в этом цикле.
