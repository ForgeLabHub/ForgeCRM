# Модуль: config

> Метаданные сгенерированы `scripts/gen-module-docs.py` из кода. Не править
> вручную факты; для изменений — перегенерировать.

## 1. Назначение и границы
Package config loads and validates ForgeCRM configuration from the environment.

## 3. Контракт
Публичный Go-API:
- `func AIProviderKinds`
- `type AIConfig`
- `type BootstrapConfig`
- `type Config`
- `type EmailConfig`
- `type MCPConfig`
- `type OIDCConfig`
- `type RetentionConfig`
- `type StorageConfig`
- `type TelegramConfig`

HTTP-маршруты, если есть, объявлены в `internal/api` (слой композиции) и отражены
в `docs/api/openapi.json`.

## 6. Зависимости
Внутренние: `database`, `httpx`, `retention`.

## 8. Сборка и запуск
```bash
cd backend
go build ./internal/config
go test ./internal/config/...
```

## 9. Перенос в другой проект
```bash
./scripts/extract-test/run.sh config   # доказывает извлечение
```
Затем скопируйте пакет и перечисленные выше зависимости, перепишите импорты
`github.com/geff1778/forgecrm/internal/config` на путь вашего проекта и примените нужные миграции.

## 11. Ограничения
Модуль живёт в одном Go-модуле ForgeCRM (ADR 0001); переносимость доказана
харнессом извлечения, а не отдельным `go.mod`.
